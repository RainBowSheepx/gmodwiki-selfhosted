# Trolleybus System — генератор документации

Источник правды для всех страниц документации аддона
[Garry's Mod Trolleybus System](https://github.com/ShadowBonnieRUS/Garry-s-Mod-Trolleybus-System)
на self-hosted вики: библиотека `Trolleybus_System`, класс `Trolleybus`, 19 систем,
entity, хуки, информаторы — порядка 570 страниц.

## Запуск

```sh
node run.mjs
```

Идемпотентно публикует все страницы через API вики: новые создаёт (POST),
существующие обновляет (PUT). Повторный запуск безопасен.

| Переменная окружения | По умолчанию | Что делает |
|---|---|---|
| `WIKI_BASE` | `http://127.0.0.1:4321` | адрес вики, куда публиковать |
| `TROLLEYBUS_SRC` | — | путь к распакованным исходникам аддона (папка с `lua/` внутри) |

## Исходники аддона

Генератору нужны исходники аддона (для сигнатур методов и ссылок View Source).
Ищутся они так:

1. `TROLLEYBUS_SRC`, если задана;
2. `../Garry-s-Mod-Trolleybus-System-master` (рядом с генератором);
3. иначе архив ветки master скачивается с GitHub и распаковывается в путь из п. 2
   автоматически (без внешних зависимостей — только Node.js).

Исходники аддона защищены авторским правом и в репозиторий не коммитятся
(закрыты через `.gitignore`).

## Файлы

| Файл | Назначение |
|---|---|
| `run.mjs` | публикатор: собирает все страницы, вставляет теги `<file>` (View Source), шлёт в API |
| `gen.mjs` | хелперы разметки (`<function>`-страницы библиотеки/классов/хуков) |
| `pages_core.mjs` | библиотека `Trolleybus_System`, класс `Trolleybus`, обзорные страницы |
| `pages_rest.mjs` | хуки, информаторы, прочие страницы |
| `pages_systems.mjs` | обзорные страницы систем |
| `pages_methods.mjs` | страницы методов систем и entity (по `signatures.json`), страницы entity |
| `extract_sigs.mjs` | извлекает сигнатуры `SYSTEM:`/`ENT:` методов из исходников → `signatures.json` |
| `sourcemap.mjs` | находит определение каждой функции в исходниках (файл + строки) для кнопки View Source |
| `addon_sources.mjs` | поиск/автозагрузка исходников аддона (п. «Исходники аддона») |

`extract_sigs.mjs` запускается отдельно (`node extract_sigs.mjs`) только когда
обновились исходники аддона — его результат `signatures.json` закоммичен.

Страницы позже в списке перекрывают ранние с тем же адресом, поэтому
`pages_methods.mjs` публикуется последним.
